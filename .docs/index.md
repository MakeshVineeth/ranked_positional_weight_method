# Calculate RPW

Calculate RPW is a cross-platform, offline assembly line balancing calculator built with Flutter and Material 3. It implements the Helgeson and Birnie Ranked Positional Weight (RPW) method for Android (phones, foldables, tablets, and Wear OS), Web browsers, and Windows.

## Key Capabilities

- **Dual Input Modes**: Use the Guided Form to enter connections, task times, and cycle time visually, or switch to Quick Text Mode for fast space-separated entry.
- **Built-in Examples**: Load textbook 6-node, 8-node parallel, or oversized-task edge cases with one tap.
- **Complete Balancing Metrics**: Computes arrow chains, ranked RPW priority tables, balanced workstations, station idle times, balance delay, line efficiency, and production rate.
- **Adaptive Material 3 UI**: Responds smoothly to window resizing, foldable hinges, display cutouts, multi-window layouts, and Wear OS screens.
- **Offline and Private**: Zero tracking, zero telemetry, and zero Android permissions required.
